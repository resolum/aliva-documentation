## Pull Requests

Antes de integrar una rama, cada integrante debe verificar que:

- La sección en Markdown se muestra correctamente.
- Las rutas de imágenes funcionen.
- Las tablas son legibles.
- Los títulos respeten la numeración del informe (No agregar más títulos, ya están por defecto).
- El cambio corresponda a la sección asignada.
- Los commits sigan la convención definida (ej.: feat: add user stories section).
- La rama esté actualizada con los últimos cambios de `develop` (Antes de desarrollar en la rama, hacer pull desde develop).
